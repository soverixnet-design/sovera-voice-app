# Reseller and profile levels

Version 0.6 connects private reseller applications, account status and server-managed profile levels to Supabase.

- Profile UID remains generated by the database, with a Copy ID action. Internal auth UUID is not displayed.
- Wealth, Charm and VIP read from `sovera_profile_levels`. Missing rows display a dash, not an invented level. No level calculation or entitlement is enabled.
- Signed-in members may submit one reseller application, initially pending. They cannot edit the status.
- Only trusted server/owner database operations can provision reseller accounts or update tier, status and coin quota. `member_role` is unchanged.
- Quota is informational in this version. Recipient lookup, recharge transfers and recharge history remain unavailable until an atomic wallet ledger and owner management flow are implemented. No coins are issued or debited by this release.
- No client can write reseller account balances or profile levels; each user can read only their own rows. RLS tests used rollback-only synthetic users.
- Google OAuth configuration remains a prerequisite for live account features. Guest preview is isolated from Supabase account actions.
