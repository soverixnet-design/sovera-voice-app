# Sovera 3D UI artwork

Six original icons generated using the built-in image generation tool, then exported to 256 px WebP with transparency preserved. All six runtime assets total approximately 107 KB. Local assets require no network requests. Labels, tap targets and voice state remain controlled by their existing widgets.

- diamond-gift.webp: room gift box and event rewards
- coin-gift.webp: Coin reward and recharge rewards
- mic-on.webp: microphone currently live
- mic-off.webp: microphone currently muted
- messages.webp: inbox and private messages
- notice.webp: official notices and event announcements

## Prompt set

Common prompt: A single original production-ready icon for the Sovera voice chat app; polished soft 3D render, rounded bevels, rich clean materials, softbox lighting from top left, isolated centered on a transparent alpha background, clear silhouette at 32–64 px, no text, logo, watermark, floor or UI card. Entire object contained with consistent scale and camera.

Subjects:
1. Open violet present box, lavender bow to the left, faceted cyan diamonds above.
2. Open coral-red present box, gold ribbon and bow, thick gold coins with embossed stars.
3. Microphone-on button, emerald bevel, pearl inset, dark navy upright microphone.
4. Microphone-muted button, coral-red bevel, pearl inset, navy microphone crossed by red slash.
5. Overlapping cyan and lavender chat bubbles, exactly three pearl raised dots.
6. Violet megaphone, gold rim, gold grip and rear collar, mouth directed upper left.

Original full-size generated PNGs are kept separately during creation; only the optimized transparent files above are bundled in the app. Reference images were used as visual direction, not copied into the app.
