# Room media update

The existing room design is retained. Tap the circular room picture in the header to choose a gallery image. In a saved room only its owner can edit it; the image is normalized to PNG and saved in the private `sovera-room-photos` bucket. Opening that room reloads the saved image. Offline preview pictures last only for the current screen.

Gift selections open an animated card. The cards remain explicitly labelled as previews: this repository does not yet implement live gift transactions, recipients, RTC, or synchronized room presence. No balance is charged by these cards.

Entry arrivals and gift cards use three original synthesized sound effects, with a mute toggle. Closing a visual or backgrounding the app stops its sound. iOS photo usage text is generated by `scripts/configure_mobile_auth.py`; Android uses the system gallery picker without broad storage permission.

Supabase migration `fix_room_photo_object_ownership` corrects the existing Storage policies to compare `storage.objects.name`, rather than the room's display name. A rolled-back database test confirmed the owner can write the expected object and a different user cannot write it. Existing owner-only room-row RLS and the owner/room photo path constraint are retained.

Remaining integration: live voice, sending gifts between real participants, and real-time profile image updates for already-open rooms. Reopening a room reloads the current picture. Device gallery and audible playback still need an Android/iOS device check.
